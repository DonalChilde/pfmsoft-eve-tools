EVE copy paste tools

Local-first helpers for text copied to and from the EVE Online client. Use the nav bar to select a tool.

Each tool is a standalone page that runs entirely in your browser. No ESI access or EVE account is required, and all state is lost when a page reloads.

Multi-buy

Paste inventory or a material list, track what you have on hand, multiply material sets, and export a multi-buy list of only the items you still need.
