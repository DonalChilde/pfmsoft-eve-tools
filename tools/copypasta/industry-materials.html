Industry Materials to Markdown

Paste the text copied from an EVE Online Industry activity. The tool runs locally in this browser; it does not use ESI or store data. Activity settings are included as metadata and do not change the pasted material quantities.

Industry input

Activity

Verify the invention result name before using this output; some blueprints invent into a different name.

The selected activity controls the output and required fields. Paste the blueprint line first, followed by the section names and tab-separated material rows; the copied text has no activity heading. Trailing empty tab columns on headings are supported.

Markdown output

Review the Markdown below, then copy it or select the text to copy manually. A Multibuy table combines required quantities from all material sections. It does not consider available materials or subtract them from the required quantities.
